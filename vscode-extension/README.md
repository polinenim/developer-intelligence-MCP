# Developer Intelligence MCP — VS Code extension (minimal)

This folder contains a minimal, local VS Code extension used for development.

How to run locally

1. Open the `developer-intelligence-mcp` workspace in VS Code.
2. Open the `vscode-extension` folder as the extension root.
3. Press `F5` to launch the Extension Development Host.
4. In the Extension Development Host window open the Command Palette and run "Developer Intelligence: Ask Question" — it should show a confirmation message.

Notes
- This extension is intentionally minimal: one command that shows a message.
- It is not connected to Python or any project internals yet.
